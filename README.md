<h1>
<img src="https://img.icons8.com/?size=100&id=ZtLgUqs1Z5TR&format=png&color=000000" width="40"/>
   Sobre o Projeto
</h1>

Este projeto foi desenvolvido com o objetivo de reunir minhas principais informações profissionais em um único lugar.

No portfólio é possível conhecer um pouco sobre minha trajetória, visualizar meus projetos, acessar minhas redes sociais, explorar minhas habilidades técnicas e navegar por uma interface moderna, responsiva e interativa.

<h1>
<img src="https://img.icons8.com/?size=100&id=108811&format=png&color=000000" width="60" alt="Executar"/>
Como executar
</h1>

Clone o repositório:

```bash
git clone https://github.com/RayssaZsilva/Portfolio-rayssa.git
```

Entre na pasta:

```bash
cd Portfolio-rayssa
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Abra no navegador:

```
http://localhost:5173
```
